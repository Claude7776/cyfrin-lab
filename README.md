# ⛓️ Local Blockchain with Anvil

Start the local blockchain:

```bash
anvil
```

Anvil provides a local Ethereum-compatible development network.

Default RPC:

```text
http://127.0.0.1:8545
```

Default local Chain ID:

```text
31337
```

The accounts generated by Anvil are **local development accounts only**.

> ⚠️ Never use Anvil's default private keys with real funds.

---

# 📦 Deploying a Contract

Deploy the `Counter` contract locally:

```bash
forge script script/Counter.s.sol:CounterScript \
  --rpc-url http://127.0.0.1:8545 \
  --broadcast \
  --private-key YOUR_ANVIL_PRIVATE_KEY
```

Foundry stores deployment information under:

```text
broadcast/
```

---

# 🔎 Interacting with the Contract

Once deployed, the contract can be interacted with using `cast`.

## Read contract state

```bash
cast call CONTRACT_ADDRESS \
  "number()" \
  --rpc-url http://127.0.0.1:8545
```

## Modify contract state

```bash
cast send CONTRACT_ADDRESS \
  "setNumber(uint256)" 42 \
  --rpc-url http://127.0.0.1:8545 \
  --private-key YOUR_ANVIL_PRIVATE_KEY
```

## Verify the state

```bash
cast call CONTRACT_ADDRESS \
  "number()" \
  --rpc-url http://127.0.0.1:8545
```

Expected value:

```text
42
```

# 🛡️ Security Principles

This repository follows several security principles:

* Never test unauthorized production systems.
* Prefer isolated local environments.
* Never use real funds for experiments.
* Never commit real private keys.
* Keep secrets outside source code.
* Reproduce vulnerabilities locally.
* Write regression tests after fixing vulnerabilities.
* Automate repetitive security workflows.
* Treat smart contracts as security-critical software.

---

# 🔐 Secrets Management

Local Anvil private keys are used exclusively for development.

Real credentials should **never** be committed to Git.

Recommended approach:

```bash
export ANVIL_PRIVATE_KEY="..."
```

Then use:

```bash
$ANVIL_PRIVATE_KEY
```

inside scripts.

Before pushing changes:

```bash
git status
git diff
```

and verify that no real secrets are present.
